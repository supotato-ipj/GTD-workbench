# ③ 合并范围争议意见

Status: ready-for-human
Type: task
主办: 运营部门（他人执笔）｜协办: 我（审核验收）
硬期限: **示例：10/26 周一上午**
触碰日: 示例：待执笔人交稿

## 目标

交付物是一份给决策层看的书面意见；成功标准是口径被认可，
卡点是证据而不是法条。

## 我的角色

材料已安排人员编写，**我只审不写**。所以我的产出物是下面这份验收清单，而不是稿件本身。

## 验收清单（审稿时逐条勾）

1. 事实部分只写有证据的。
2. 每个法律结论都落到条文号。
3. 举证责任分配写清楚了——不能默认由对方承担。
4. 「不介入」和「不履职」是两件事，材料里不能混写。
5. 主动方案至少给一条，否则决策层只会追问「那我们做什么」。
6. 查不到证据的条目标出来，不要跳过——空格本身是信息。

## 卡点

等执笔人交稿。在交稿之前我这边不推进——审稿意见没有底稿可对照。

# 画布结构：外层六个纸箱，内层天刻度时间轴

> **Status**: superseded by [ADR-0009](0009-工作台是焦点引导器.md)（2026-11-07）。
> 本文件正文保留原样，不再改写。取代它的是 [ADR-0009](0009-工作台是焦点引导器.md)（工作台是焦点引导器）、[ADR-0010](0010-焦点资格与排序.md)（焦点资格与排序）、[ADR-0011](0011-容量参数的初始化与调校.md)（容量参数的初始化与调校）。六箱画布本身不删除，降为下钻层。

## 背景

工作台要同时展示三样东西：**完成情况**、**当前工作计划**、**未来工作任务**。用便贴纸和纸箱的隐喻来承载它们，首先要定下"纸箱对应什么、便贴对应什么"。

## 决定

### 外层：六个纸箱 = 六个 GTD 容器

`收集箱` / `项目` / `执行` / `等待` / `日历` / `可能`，与 [ADR-0005](0005-时间档降为标签.md) 定的容器一一对应。收集箱即滴答 inbox。

- **项目画成箱签，不画成便贴。** 箱签只写项目名和下一步指针（ADR-0004：项目不带子任务）。项目一旦画成便贴，画布就会变成一个挂子任务的地方，这是 ADR-0004 明写的警戒线。
- **日历箱按"外部约定时刻"口径过滤**。它底下有 200 多条周期项（工作日重复的固定动作），按 ADR-0004 的定义过滤后，未完成只剩个位数。空箱是结论，不是缺陷。
- **可能清单默认折叠**。GLOSSARY 说它是"当前不投入、但不想丢失的事"，本就不该占版面。

### 内层：天刻度时间轴

`今天 / 明天 / 本周 / 以后`，默认视野只铺**今天 + 本周**，其余折叠成计数条。

选天不选周：容量账整份按天排（可用窗口的具体数值属个人配置，不进本仓库，见 [ADR-0011](0011-容量参数的初始化与调校.md)），"深度任务一天只排 1 个""一天两个深度任务必崩"都是已验证的判断。天刻度能一眼把违规顶出来。

**本周主攻从滴答推导**：本周内未完成、且带 `深度` 标签的动作。不读计划文档的「本周三件主攻」段落。

> 这带来一次已知的不一致：计划文档里写的本周主攻，与滴答的 `深度` 标签推出来的名单不一定一致（降级过的动作改了标签、名单没改）。**以滴答为准**，因为 ADR-0004 的核心不变式是"一个动作只存在一次"；两份名单并存就是 ADR-0003 判为失败的双写，而且它已经漂了。

### 已沉底区

滴答里已勾选完成的条目，按天堆叠，窗口取最近 7 天；每个纸箱角标另标一个"完成 n"。这是**展示区**，不是 GTD 容器——回收箱不建，直接删（ADR-0004）。

### 规则角标

违反容器规则的便贴打一个角标（例如等待清单缺"到期没回做什么"），点开看。**不做独立的校验面板**——那会变成第二个待办清单。

检查项取自 GLOSSARY 与 ADR-0005 的硬规则：等待清单四样齐不齐、执行清单每条动作是否恰好一个时间档标签、项目是否挂了子任务。

### 布局与动画

- **固定看板**：六个箱横向排开，箱内便贴纵向堆叠、箱内独立滚动；不可拖动、不可缩放。自由画布能摆出好看的版面，但会让"箱内按时间排序"这条唯一有用的排序失效，也会诱导重新排版。
- **拿起来有手感但不落位**：拖起来有阻尼和倾斜，松手弹回原位。零位置管理。
- **入场动画**：打开画布时，便签按时间轴顺序依次贴上，读起来像一天的推进。
- **状态迁移动画靠 diff**：每次拉数时与上次快照比对，检测到"新完成 / 新改期 / 新换容器"才播对应动画。快照存浏览器本地（localStorage），不落仓库文件。
- **不演"时间流逝"**：不模拟从早到晚的过程。只演真实发生过的差异。

### 质感

用宿主主题 token 做底，纸箱只保留折角、阴影、轻微纸张纹理。**不换字体、不换配色**：宿主有明暗两套主题，浮层与主区配色不一致会刺眼；中文手写体在 Windows 上常常找不到、最后回退成难看的默认字。折角 + 阴影 + 纸纹这三样是质感的来源，且不依赖字体。

## 后果

- 画布上"完成情况"的全部含义 = 滴答勾选。勾选失真的代价见 [ADR-0006](0006-工作台是只读视图.md)。
- 本周主攻与计划文档的名单会不一致，以滴答为准。**降级一件主攻的正确做法是改它的时间档标签，不是改计划文档的列表。**
- 纸箱数量固定为 6，新增容器要同时改画布、ADR-0005 和 GLOSSARY。
- 规则角标的价值主要体现在**每天新增**的条目上，不是存量。验收看的是机制能工作，不是角标数量。
